## 🌟 Overview

**The Digital Universe** is a production-grade, immersive personal developer portfolio engineered to showcase verified full-stack applications, telemetry observability architectures, applied machine learning systems, and academic achievements.

Built with **React 19**, **TypeScript**, **Three.js / React Three Fiber**, **Tailwind CSS**, and **Vitest**, the application adheres to strict architectural principles:

- **Decoupled 3D & DOM Layers:** A persistent WebGL canvas provides deep-space celestial parallax while semantic HTML delivers high-contrast, accessible content.
- **Strict Verification Policy:** Only verified GitHub repositories, tested metrics, and genuine credentials are featured. No fabricated statistics, employment history, or placeholder links.
- **Graceful Degradation:** Resilient WebGL error handling, automated responsive DPR throttling, and screen-reader compliant navigation.

## 📜 Development & Verification Commands

### Prerequisites

- Node.js `v20+` (Developed and verified on Node `v24.18.0`)
- npm `v10+` (Verified on npm `11.16.0`)

### Setup & Run

```bash
# Clone the repository
git clone https://github.com/andhony07/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server (http://localhost:3000)
npm run dev

# Run strict TypeScript compilation check
npx tsc --noEmit

# Run unit and component test suites (Vitest)
npm test

# Run ESLint validation
npm run lint

# Execute production build
npm run build
```
